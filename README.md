# Smart Healthcare PM System

A professional, full-stack Project Management and Earned Value Management (EVM) system built for a 5-hospital healthcare network case study. Developed as a university midterm viva submission.

## Features & Modules
* **Overview & Dashboard:** High-level project summary and key performance indicators.
* **Scope & Change Management:** Formal change request logging with automated cost and schedule impact analysis.
* **Schedule & WBS Management:** Interactive work breakdown structure and task tracking.
* **Cost Management & EVM:** Programmatic calculations for Planned Value (PV), Earned Value (EV), Actual Cost (AC), CPI, and SPI with automated threshold warning banners.
* **Quality & Risk Matrix:** Risk prioritization and mitigation tracking.

## Tech Stack
* **Frontend:** React.js, Vite, Bootstrap, HTML5, CSS3
* **State Management & Logic:** Programmatic EVM calculation engines and dynamic component rendering

## System Test Cases Summary
All core modules have been rigorously tested for programmatic accuracy, dynamic form updates, and automated threshold alerts (Over Budget / Delayed indicators).
